# 🎬 Movie Rating Analysis

A beginner-friendly **Python Data Analysis and Visualization project** that analyzes movie ratings using **Pandas, Matplotlib, and Seaborn**.

---

## 📌 Project Overview

The **Movie Rating Analysis** project analyzes a dataset of movies based on different rating categories:

* ⭐ Story Rating
* 🎬 Direction Rating
* 🎭 Acting Rating
* 🏆 Overall Rating

The project uses Python data analysis techniques to calculate statistics, identify highly rated movies, study relationships between ratings, and visualize the results through different graphs.

---

## 🎯 Objectives

The main objectives of this project are:

* Analyze movie rating data using **Pandas**
* Display and understand the dataset
* Find the first and last records
* Check dataset information and data types
* Calculate average ratings
* Find minimum and maximum ratings
* Identify the highest and lowest rated movies
* Analyze correlations between rating categories
* Visualize movie ratings using different graphs
